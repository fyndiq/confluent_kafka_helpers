# Migration Guide for v0.2

Migrating from `0.1` (`v0.1`) to the latest `0.2.x` (`v0.2`).

## Required changes

- **`AvroMessageLoader` keyword**: the constructor argument is now `config` (was `loader_config`).
- **Loader consumer config**: `config['consumer']` must already contain `default.topic.config`. The loader writes `auto.offset.reset = 'earliest'` into that nested dict (a missing key raises `KeyError`).

### Migration steps

1. Rename the keyword and ensure the nested topic config exists:

   ```python
   # Before (0.1)
   AvroMessageLoader(loader_config)

   # After (0.2)
   loader_config['consumer'].setdefault('default.topic.config', {})
   AvroMessageLoader(loader_config)
   ```

## Optional changes

- **Earliest reset on the loader consumer** (`0.2`): the loader now forces `auto.offset.reset='earliest'` so a load starts from the beginning of the partition.
