# Migration Guide for v0.4

Migrating from `0.3` (`v0.3`) to the latest `0.4.x` (`v0.4.3`).

## Required changes

- **Consumer yields `Message`**: `AvroConsumer` no longer yields a raw Confluent message. Use `message.value` (attribute) and `message._meta` for key/partition/offset/topic/timestamp.
- **Loader returns a generator of `Message`s**: `AvroMessageLoader.load` used to return a `list` of decoded values. It now returns a `MessageGenerator` that yields `Message` objects. Iterate it (or use it as a context manager); do not treat the return value as a list of values.
- **`confluent-kafka[avro]==0.11.0`**: the client is pinned again (0.3 allowed `>=0.11.0`).

### Migration steps

1. Read the wrapper instead of the raw Kafka message:

   ```python
   # Before (0.3)
   for message in consumer:
       process(message.value())

   # After (0.4)
   for message in consumer:
       process(message.value)
       # message._meta.key, .partition, .offset, .topic, .timestamp, .datetime
   ```

2. Iterate the loader (and take `.value` if you need the payload only):

   ```python
   # Before (0.3)
   values = loader.load(key)          # list of payloads
   process(values[0])

   # After (0.4)
   with loader.load(key) as messages:  # MessageGenerator
       for message in messages:
           process(message.value)
   ```

## Optional changes

- **`stop_on_eof` / `non_blocking`** (`0.4`): consumer config flags to stop at partition EOF or yield `None` when idle.
- **Producer `acks=all`**: new default.
- **Loader closes on process exit**: `atexit` now closes the loader consumer.
- **`get_latest_cached_schema`**: LRU-cached schema lookup on `AvroSchemaRegistry`.
