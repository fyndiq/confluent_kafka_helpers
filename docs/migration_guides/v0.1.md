# Migration Guide for v0.1

First public release (`v0.1`). There is no prior compat line.

## Required changes

None — v0.1 is the first public release; there is nothing to migrate from.

### Migration steps

1. Install `confluent_kafka_helpers` 0.1 (`confluent-kafka[avro]==0.11.0`).

## Optional changes

- **`AvroConsumer`**: iterate a topic (or list of topics) with `AvroConsumer(topic, config, timeout=0.1)`.
- **`AvroProducer`**: produce Avro messages; config requires `schema.registry.url`, `key_subject_name`, `value_subject_name`, and `default_topic`. `produce(key, value)` flushes after every send.
- **`AvroMessageLoader`**: load all stored messages for a key from one partition; returns a list of values.
- **`AvroSchemaRegistry`**: fetch, register, and serialize with the Confluent schema registry.
