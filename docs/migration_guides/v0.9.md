# Migration Guide for v0.9

Migrating from `0.8` (`v0.8.0`) to the latest `0.9.x` (`v0.9.0`).

## Required changes

- **`confluent-kafka` upper bound is `1.6.1`** (was `1.5.0`); `fastavro` upper bound is `1.1.0`.
- **Producer `max.in.flight=1`**: restored as a default so `enable.idempotence` matches librdkafka's requirement. Override only if you have disabled idempotence.

### Migration steps

1. Allow `confluent-kafka<=1.6.1` (and `fastavro<=1.1.0`) in your environment.

## Optional changes

- **`**kwargs` forwarded** (`0.9.0`): extra constructor kwargs go to the underlying Confluent `AvroConsumer` / `AvroProducer` (e.g. a custom logger).
