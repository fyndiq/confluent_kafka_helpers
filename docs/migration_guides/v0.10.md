# Migration Guide for v0.10

Migrating from `0.9` (`v0.9.0`) to the latest `0.10.x` (`0.10.5`). `0.10.3`–`0.10.5` were never tagged; `0.10.5` is the last `setup.py` bump before 1.0.0.

## Required changes

- **`confluent-kafka` 2.x** (`0.10.5`): the pin moves from `>=1.0.0,<=1.6.1` to `confluent-kafka[avro,schema-registry]==2.*`. This is a major client upgrade inside the 0.10 line.
- **Direct `fastavro` / `avro-python3` deps removed** (`0.10.3`): Avro support comes from the `confluent-kafka` extra. From `0.10.4` that extra is `[avro,schema-registry]`.

### Migration steps

1. Install a 2.x client with Avro extras (this is what `0.10.5` pulls in):

   ```text
   pip install 'confluent-kafka[avro,schema-registry]==2.*'
   ```

   Drop standalone `fastavro` / `avro-python3` pins unless your app imports them directly.

2. Re-test consume/produce against a 2.x client — config key names and error codes follow the 2.x Confluent Python client.

## Optional changes

- **OpenTracing span leak fix** (`0.10.1`): `start_active_span` now closes the scope after the span finishes. No API change; upgrade if you use the `opentracing` extra.
