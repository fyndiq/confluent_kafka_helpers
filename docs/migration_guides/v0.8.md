# Migration Guide for v0.8

Migrating from `0.7` (`v0.7.10`) to the latest `0.8.x` (`v0.8.0`).

## Required changes

None — upgrading to v0.8 is drop-in; no code changes required. Tracing is a no-op unless the `opentracing` extra is installed.

### Migration steps

1. Upgrade to `confluent-kafka-helpers==0.8.0`.

## Optional changes

- **OpenTracing extra** (`0.8.0`): `pip install confluent-kafka-helpers[opentracing]` instruments consume, commit, and produce. Without the extra, a null tracer is used.
- **`produce(..., headers=)`** (`0.8.0`): pass a header dict; tracing injects a span context into it.
- **Non-bytes header values** (`0.8.0`): `decode_kafka_headers` leaves non-`bytes` values as-is instead of calling `.decode`.
